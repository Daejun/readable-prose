prose plugin: 답변과 글을 쓸 때 지킬 규칙. 한 줄에 규칙 하나다.

구조
- 결론과 요청을 첫 문장에 둔다.
- 둘 이상의 단계·경우·원인은 짧은 label을 붙인 목록으로 나눈다.
- 항목이 세 문장을 넘으면 하위 목록으로 나눈다.
- 목록이나 인용 앞에 예고만 하는 문장("~은 이렇습니다")을 두지 않는다.
- 곁가지는 "참고로"로 시작해 맨 뒤에 둔다.

목록 표지 (수준별)
- 한 수준만 쓸 때: `-`. 순서가 있으면 `1.`
- 두 수준을 쓸 때: 1수준은 `1.`, 2수준은 `-`. 1수준에 순서가 없어도 `1.`을 쓴다
- 세 수준은 쓰지 않는다. 표로 바꾸거나 3수준을 2수준 항목의 문장으로 합친다
- 두 수준에 같은 표지를 쓰지 않는다

문장
- 한 문장에 판정 하나만 넣는다.
- 빠진 주어와 동사를 채운다.
- 이 session에서 붙인 번호·label·약어는 처음 나올 때 한 구로 푼다.
- 측정값에는 무엇을 쟀는지 붙인다.
- "짧게"는 주장 수를 줄이는 것이다. 조사·연결어를 빼거나 "→"로 동사를 대신하지 않는다.

commit message
- 72열에서 줄을 바꾼다.
- 본문은 맥락, 문제, 해결을 다른 문단에 쓴다.
- 서로 독립된 변경·경우·bug를 셋 이상 나열하거나, 둘이어도 항목마다 두 줄을 넘으면 `- ` 목록으로 쓴다. 그 밖에는 문단으로 쓴다.
- 목록 앞에는 목록의 목적을 말하는 문장을 둔다.
- markdown bold와 header를 쓰지 않는다.

게시물
- PR body, review 답글, issue, 보고서를 쓰거나 남의 글·이미 쓴 글을 고칠 때는 prose:readable skill을 불러 사실 대조까지 거친다.
